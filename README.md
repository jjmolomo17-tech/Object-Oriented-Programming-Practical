# Object-Oriented-Programming-Practical

## Food Delivery System
 Built by:Joy Molomo

## Project Overview
This project demonstrates Object-Oriented Programming principles using a Food Delivery System built in JavaScript.

The system allows customers to:

Create food items
Add food items to an order
Calculate food costs
Calculate delivery fees
Display order summaries
Calculate final totals

## OOP Principles Demonstrated
1. Encapsulation
The FoodItem class uses a private property:

#price
getPrice()
setPrice()

3. Abstraction
The user only interacts with methods such as:

addItem()
calculateFinalTotal()
displayOrderSummary()

The internal calculations are hidden.

4. Polymorphism
Each food type overrides:

calculateDeliveryFee()

The same method produces different results depending on the object type.

Example:

Pizza -> R30

Burger -> R20

Drink -> R10

Dessert -> R15
